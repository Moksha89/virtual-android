Help & Documentation

Getting Started

1. Enable USB Debugging on Your Android Device

  1. Go to Settings → About Phone
  2. Tap Build Number 7 times to enable Developer Options
  3. Go back to Settings → Developer Options
  4. Enable USB Debugging

2. Connect Your Device

  1. Connect your Android device to your computer via USB
  2. When prompted on your phone, tap Allow to authorize USB debugging
  3. Check "Always allow from this computer" for convenience
  4. Your device should appear in the Devices list

3. Start a Session

  1. Click on a connected device in the Devices list
  2. Click Start Session to begin remote control
  3. A new window will open showing your device's screen
  4. Use your mouse and keyboard to control the device

Troubleshooting

Device Not Detected

  • Make sure USB Debugging is enabled
  • Try a different USB cable (use the original cable if possible)
  • Try a different USB port
  • Click "Restart ADB" in the Devices tab
  • On Windows, install USB drivers from Settings

Device Shows "Unauthorized"

  • Check your phone for a USB debugging authorization prompt
  • Tap "Allow" on the prompt
  • If no prompt appears, revoke USB debugging authorizations in Developer Options and reconnect

Screen Mirroring Not Working

  • Make sure scrcpy is installed (check Settings)
  • Try lowering the resolution in Settings
  • Some devices may require specific USB modes - try "File Transfer" mode

Banking App Safety

Important Information

This application uses ADB (Android Debug Bridge) to control your device, which is the same method used by Android developers. This approach is:

  • Bank-safe: No Android app is installed on your device
  • No root required: Works with standard Android devices
  • No accessibility services: Doesn't trigger banking app security

Your banking apps should work normally while using this remote control system.
